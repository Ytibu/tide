# Tide 项目简介

## 🌊 Tide

> *不争先，争的是滔滔不绝。*

Tide 是一个面向 C++ 的服务器框架，让网络连接如同潮汐一样默默无声、涛涛不绝。
它不试图成为最快、最“现代”的框架，而是像大海一样：默认就可靠，不需要时时炫耀存在感。

## 🚀 快速开始

### 最简示例

```bash
# 配置并构建
cmake -S . -B build && cmake --build build
```

### 一键生成、编译并安装

```bash
./generate.sh
```
